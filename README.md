# PAMoR Project Website

Project page for **PAMoR: Parameterized Affective Motion Generation in Real Time for Humanoid Robots**.

- Paper: https://arxiv.org/html/2608.28213v1
- Website: https://aaron668pan.github.io/PAMoR/

The site is built with Next.js-compatible Vinext and deployed automatically to GitHub Pages from the `main` branch.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
